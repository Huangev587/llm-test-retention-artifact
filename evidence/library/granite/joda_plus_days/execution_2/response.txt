1. ```java
@Test
public void testPlusDaysZero() {
    LocalDate original = LocalDate.of(1950, 1, 1);
    LocalDate result = original.plusDays(0);
    Assert.assertEquals(original, result);
}
```

2. ```java
@Test
public void testPlusDaysPositive() {
    LocalDate original = LocalDate.of(1950, 1, 1);
    LocalDate result = original.plusDays(10);
    Assert.assertEquals(LocalDate.of(1950, 1, 11), result);
}
```

3. ```java
@Test
public void testPlusDaysNegative() {
    LocalDate original = LocalDate.of(1950, 12, 31);
    LocalDate result = original.plusDays(-10);
    Assert.assertEquals(LocalDate.of(1950, 12, 21), result);
}
```

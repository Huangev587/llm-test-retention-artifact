1. ```java
@Test
public void testCountMatchesNullStr() {
    Assert.assertEquals(0, StringUtils.countMatches(null, "a"));
    Assert.assertEquals(0, StringUtils.countMatches(null, ""));
}
```

2. ```java
@Test
public void testCountMatchesNullSub() {
    Assert.assertEquals(0, StringUtils.countMatches("a", null));
    Assert.assertEquals(0, StringUtils.countMatches("", null));
}

```

3. ```java
@Test

7. ```java
@Test
public void testReverseAsciiMax() {
    Assert.assertEquals("0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ", StringUtils.reverse(new String(new char[128])))
       .equals(new String(new char[128]).reverse().toCharArray());
}
```

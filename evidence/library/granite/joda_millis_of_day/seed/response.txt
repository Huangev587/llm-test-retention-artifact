1. ```java
@Test
public void testGetMillisOfDay() throws Exception {
    LocalTime time = LocalTime.of(0, 0, 0, 123);
    int expected = 123 * 1000;
    int actual = time.getMillisOfDay();
    assertEquals(expected, actual);
}
```
